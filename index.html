Terms and abbreviations

FCFS First-Come, First-ServedSJF Shortest Job FirstNP Priority Non-Preemptive PrioritySRTF Shortest Remaining Time FirstRR Round Robinms milliseconds, the unit for every time here
AT · Arrival Time
When the process enters the ready queue and can start asking for the CPU.
BT · Burst Time
How much CPU time the process needs in total to finish.
Start · Start Time
The first moment the process actually gets the CPU.
CT · Completion Time
The moment the process finishes. Read it off the end of its last bar in the Gantt chart.
TAT · Turnaround Time
Total time from arrival to finish.TAT = CT − AT
WT · Waiting Time
Time spent waiting in the ready queue, not running.WT = TAT − BT
Priority
A rank given to each process. Here 1 = highest, so the lowest number goes first.
Remaining time
How much of the burst a process still needs. It shrinks each time the process runs.
q · Time Quantum
The longest a process may run in one turn under Round Robin. These quizzes use q = 2 ms.
Ready queue
The processes that have arrived and are waiting for the CPU.
Gantt chart
A timeline bar showing which process runs at each moment. Bar length = time spent running.
Preemptive vs non-preemptive
Preemptive: a running process can be interrupted. Non-preemptive: once a process starts, it runs to completion.
